# 프로세싱을 통한 게임 제작 프롬프트
->프로세싱에서 돌아가는 게임을 하나 만들까 해. 화면 정 중앙 하단부에 위치한, 벽이나 구조물에 한번 부딪히면 튕기고, 두번째로 부딪히면 3x3 블록 구조물 크기 만큼의 폭발을 일으키는  탄환을 발사하는 총을 배치해줘. 그리고 화면 상단부에서 작은 블록 여러개로 이루어진 큰 구조물이 나타나는 거야. 유저는 여기서 제한된 n개의 탄환만을 받고 그 제한된 탄환 내에서 구조물의 특정 부분에 위치한 코어를 타격해 터트려야만 하는거지.
->다른거 다 좋은데, 탄환이 한번만 더 튕기게끔 코드를 고쳐줘
